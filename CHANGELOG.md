# Changelog

## 0.1.0 — 2026-11-10 — First release

- Fisheye lens by default: the screen bulges like cloth pushed up by a glass ball, with no hard edge and light on the slope. Scroll for magnification, Shift + scroll for the radius.
- One shortcut opens and closes it: running it again closes the open lens.
- It picks the focused screen on niri, Hyprland and Sway; `--monitor` still chooses one.
- Correct scale and mouse position with fractional scaling and several monitors.
- woomer's classic zoom stays as `--zoom`.
- Signed packages for pacman (`ross-fisheye-bin`), APT and DNF (`ross-fisheye`) from [repo.rossmel.com](https://repo.rossmel.com/fisheye/).
